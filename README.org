* 不正经拳论 · 书籍网站
:PROPERTIES:
:CUSTOM_ID: 不正经拳论-书籍网站
:END:
基于 Hugo 与 PaperMod 的独立网站。包含定制书籍宣传首页、三篇精选试读、全书导读、作者介绍、站内搜索与 Netlify 配置。Cloudflare Pages 已连接 GitHub：=fymen/quanlun-site=，生产分支 =main=，入口 https://quanlun-site.pages.dev/ 。源码托管于 https://github.com/fymen/quanlun-site ，未部署到 Netlify。

** 本地使用
:PROPERTIES:
:CUSTOM_ID: 本地使用
:END:
要求 Hugo *0.162.1*（本地已验证版本；PaperMod 上游要求至少 0.158.0）。主题已随仓库保存，无需 npm，也无需再下载主题。

#+begin_src sh
hugo server --bind 127.0.0.1
#+end_src

浏览器访问终端显示的地址，通常为 http://localhost:1313/ 。

构建：

#+begin_src sh
bash scripts/build.sh
# 按实际生产域名构建：
bash scripts/build.sh --baseURL https://your-domain.example/
#+end_src

生成目录 =public/= 不纳入 Git。默认 =baseURL= 为本地地址；部署时必须传入真实网址，Netlify 构建脚本会自动处理。

** 目录与编辑位置
:PROPERTIES:
:CUSTOM_ID: 目录与编辑位置
:END:
- =layouts/home.html=：Hugo 当前版本使用的定制宣传首页。
- =assets/css/extended/book.css=：站点与手机排版样式。
- =hugo.toml=：标题、描述、导航、主题设置。
- =content/read/=：精选试读，优先由书稿同步，直接修改会被覆盖。
- =content/book.org=：全书导读、版本及获取说明。
- =content/about.org=：作者介绍。只使用书稿已有信息，没有编造师承、年限和推荐语。
- =content/articles/=：后续研习札记，当前没有预置假文章。
- =static/images/=：网站使用的封面、Logo 和试读插图。
- =themes/PaperMod/=：固定版本的上游主题，出处见 =THEME.org=。

网页只发布明确选定的三篇试读，不携带全书 PDF、EPUB 或视频工程。网站完整构建不依赖书稿仓库；只有重新同步试读时才需要书稿和 Pandoc。

** 从 Org 书稿同步
:PROPERTIES:
:CUSTOM_ID: 从-org-书稿同步
:END:
网页内容与项目文档统一使用 Org 格式；页面顶部保留 Hugo front matter。第三方主题附带的 Markdown 文档保留上游格式。

要求 Python 3 与 Pandoc。默认书稿位于同级 =../martial_art/=，也可明确指定：

#+begin_src sh
python3 scripts/sync-samples.py --book-root ../martial_art
bash scripts/build.sh
#+end_src

Pandoc 不在 PATH 时，使用 =PANDOC=/path/to/pandoc python3 scripts/sync-samples.py=。单独同步《呼吸互含气住脉停》可运行 =python3 scripts/sync-samples.py --only breath_gap=；单独同步《要做神仙需练劈拳》使用 =--only piquan_quanjia=。同步脚本保留五篇的同步能力：空空静静、中和之道、先天真一之炁、呼吸互含气住脉停、要做神仙需练劈拳；保留正文与脚注，移除印刷专用指令并复制用到的图片。当前仅公开空空静静、呼吸互含气住脉停、要做神仙需练劈拳；中和之道、先天真一之炁保留为草稿，同步时自动保持 =draft = true=，常规构建不生成其页面、搜索索引或旧地址别名。每次同步后应检查脚注、图片及正文是否与书稿一致。

首页引用与导读为编辑文案，不会自动覆盖；书稿有重大变更时应人工复核这些文案。封面取自建立网站时本书 PDF 的第一页；书封变更后需单独更新。

** 在 Netlify 发布
:PROPERTIES:
:CUSTOM_ID: 在-netlify-发布
:END:
1. 将本网站仓库推送到你自己的 Git 远程仓库。
2. 在 Netlify 导入该仓库。构建命令 =bash scripts/build.sh=，发布目录 =public=，仓库自带 =netlify.toml=。
3. 生产构建使用 Netlify 的 =URL=，预览构建使用 =DEPLOY_PRIME_URL=。绑定自定义域名后重新构建，检查 canonical、站点地图与分享图片地址。
4. 部署预览和分支预览会在 robots 中禁止抓取；这不是访问权限控制。
5. 实际测试微信内访问、手机布局、图片和试读速度，检查 Netlify 账号配额。

销售入口、联系方式和视频目录尚未配置。确认真实信息后再添加；不要把付费完整版放进 =static/= 或公开仓库。

** 多语言版本

简体中文沿用根目录网址，繁体中文位于 =/zh-tw/=，英文位于 =/en/=。三种语言均提供首页、全书导读、作者介绍、搜索和当前三篇试读；其余两篇草稿不公开。

- =content/=：简体中文原文，现有同步脚本仍只更新此目录。
- =translations/zh-tw/=：繁体中文 Org 页面，以 OpenCC 的 =s2t= 转换为基础校订。
- =translations/en/=：英文 Org 译文。英文书名为本站译名，销售店铺及社交账号保留实际名称。
- =i18n/zh.json=、=i18n/zh-tw.json=、=i18n/en.json=：首页、购书、联系方式及页脚的界面文案。
- =hugo.toml=：语言名称、菜单、各语言的标题和内容目录。

各语言的 =bookCover= 配置控制首页封面，=images= 配置控制分享预览图。简体版使用 =static/images/book-cover.png=，繁体版使用 =static/images/book-cover-zh-Hant.png=，英文版使用 =static/images/book-cover-en.png=。首页统一以简体封面的尺寸比例显示；自动读取 =static/images/book-cover.png= 的尺寸作为基准，其他语言封面完整缩放并以白色留边补齐。

简体封面的地址带有基于文件 SHA-256 的版本参数，避免同名换图后继续使用一天有效期的旧缓存。下次替换图片时，同时更新 =bookCover= 与 =images= 中的 =v= 参数（文件 SHA-256 的前 12 位）。

导航栏的语言切换会优先前往同一页面的译本；没有对应译本时返回该语言首页。页面路径及文件名应在三个内容目录中保持对应，便于 Hugo 识别译本。新增站内链接时，模板使用 =relLangURL=，Org 正文使用对应语言的路径；图片统一使用 =/images/=。

原文有更新或重新同步后，请复核两种译文；同步脚本不会覆盖现有译文。只翻译当前明确公开的三篇，不将草稿自动发布到其他语言。构建后可执行以下检查：

#+begin_src sh
python3 scripts/check-languages.py public
#+end_src
